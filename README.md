## 🧠 The Hexacortex Architecture (3-2-1)

Inspired by the efficiency of a spider's web, Hexacortex processes data vibrations through a biomimetic 3-2-1 topology:

### 🕸️ The Web (3 Sensory Threads via DataHub MCP)
1. **Schema Thread:** Detects structural changes in tables/columns.
2. **Lineage Thread:** Senses breaks in data flow or orphaned datasets.
3. **Governance Thread:** Monitors unauthorized access to sensitive data.

### 🧠 The Nervous System (2 Analyzers)
1. **Noise Filter:** Ignores expected vibrations (planned updates).
2. **Triangulation Engine:** Cross-references threads to confirm true anomalies.

### 🕷️ The Spider (1 Decisor)
Generates production-ready repair code (SQL/Python/Airflow) and **writes the solution back to the DataHub graph**, ensuring the next agent inherits the knowledge.

## 🚀 Quick Start

### Prerequisites
- Python 3.10+
- Docker (to run DataHub locally) or a DataHub Cloud instance.

### Installation
```bash
pip install -r requirements.txt
```

### Configuration
Set your DataHub GMS URL in the environment variables:
```bash
export DATAHUB_GMS_URL="http://localhost:8080"
```
